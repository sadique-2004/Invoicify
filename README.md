# 🚀 Invoicify

Invoicify simplifies invoice management—create professional invoices in seconds and print or download with ease. Designed to streamline the invoicing process, Invoicify offers AI-powered assistance and a seamless user experience for businesses of all sizes.

## ✨ Features

- ✅ **Create Invoices in Seconds** – Generate professional invoices effortlessly.
- 🤖 **AI Chatbot Support** – Get real-time assistance for smooth invoice management.
- 📄 **Print or Download** – Save invoices as PDFs or print them instantly.
- 🎨 **Modern UI** – Built with Tailwind for a sleek and responsive design.

## 🛠️ Tech Stack

- **Frontend:** React, Typed.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## 📦 Installation & Setup

1. **Clone the repository**
   ```sh
   git clone https://github.com/sadique-2004/Invoicify.git
   cd Invoicify
   ```

2. **Install dependencies**
   ```sh
   npm install
   ```

3. **Start the development server**
   ```sh
   npm start
   ```

## 🚀 Deployment

To deploy Invoicify, configure the backend and frontend deployment using services like **Vercel, Netlify, or Render**.
